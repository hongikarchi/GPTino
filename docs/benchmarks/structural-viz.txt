실무 모델 변형 시각화 (ModelView 스타일): 해석이 끝난 실무 철골 결과를 뷰포트에 그려줘.
- Python 3 스크립트 컴포넌트를 만들고, 컴포넌트 자체의 닉네임(출력 소켓 이름 아님!)에 "RealModelViz"를 포함해.
- 입력: vizPath (item, str — Panel로 "C:\Users\user\Desktop\GPTino\artifacts\pynite-real-report-viz.json" 공급), scale (item, float — 슬라이더 1~500, 기본 50), colorCapMm (item, float — 슬라이더 1~200, 기본 50)
- 스크립트 동작: json 로드 → nodes[id].xyz_mm(원좌표)와 d_mm(변위 벡터 mm) → 전체 원좌표의 중심(centroid)을 빼서 원점 근처로 재배치 → edges의 각 부재에 대해:
  원형 선 = (a.xyz - centroid) to (b.xyz - centroid)
  변형 선 = 같은 좌표 + 각 노드의 d_mm × scale
  dispMm = 두 끝 노드 변위 크기(mm)의 평균, colorCapMm으로 클램프한 값도 tColor(0~1)로
- 출력: origLines (list, line), defLines (list, line), dispMm (list, float), tColor (list, float), status
- 그다음 네이티브 컴포넌트로 색상 시각화: Gradient 컴포넌트(t=tColor, 0=파랑→1=빨강)와 Custom Preview로 defLines에 색을 입혀 뷰포트에 보이게 배선해줘. origLines는 회색 재질의 별도 Custom Preview로 흐리게.
- 완료 후: defLines 개수, 최대 dispMm, 그리고 뷰포트에서 뭘 보게 되는지(어느 구역이 빨갛게 뜨는지) 보고해줘.
